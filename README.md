# 🛣️ Inventário de Degraus — Via Raposo

Sistema de inventário e monitoramento de degraus no pavimento, desenvolvido para a **Via Raposo Concessões**.

## Funcionalidades

- 📊 **Dashboard** com mapa interativo, gráficos e ranking de degraus críticos
- 📋 **Pontos Cadastrados** — edição e exclusão de registros
- 📷 **Cadastrar Fotos** — OCR automático para leitura de coordenadas, rodovia, sentido e data
